# string
A physics-informed neural network (PINN) solver and visualization of a nonlinear PDE.

https://vtechworks.lib.vt.edu/server/api/core/bitstreams/89a42861-53ba-4767-a561-9e19ee4ab77d/content


The PINN is intended to learn a parametric, continuous approximation of the transverse displacement field governed by equation (2.9) in the thesis. This will solve and visualize the full nonlinear PDE and boundary conditions without modal truncation or eigenvalue reduction. Both cases will be used to validate the PINN.
